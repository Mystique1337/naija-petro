Welcome to Naija-Petro

Nigeria-aware petroleum engineering AI

A fine-tuned Qwen3-8B assistant with a live, self-updating retrieval layer. Ask across drilling, reservoir, production, completions, EOR, and Nigerian regulation (PIA 2021, NUPRC, NMDPRA, NNPC). Every answer cites verifiable sources.

📚Grounded and cited. Answers pull from Nigerian sources and show citations you can open.
🧮Calculators. Open the 🧮 menu to run exact engineering calculations: OOIP, IPR, decline, PVT, and more.
↩︎Long answers. If a reply gets cut off, click Continue or type "continue" to finish it.
⏳The first answer is slow. The model scales to zero to save cost, so the first question after a quiet spell takes about 3 to 5 minutes while the GPU boots and the weights load. Everything after that is fast, and a status indicator shows it is still working.
